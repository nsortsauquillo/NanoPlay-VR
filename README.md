# NanoPlay-VR

Esta aplicación ofrece una experiencia interactiva basada en una colección de minijuegos, pensados para entretener, sorprender y mantener al usuario activo en todo momento. Cada uno de estos juegos propondrá un reto distinto:  otros los reflejos, la puntería o la suerte. La idea es que cada partida sea breve a la par que intensa para que resulte fácil engancharse y siempre haya algo nuevo que probar.

Los minijuegos están pensados para ser accesibles desde el primer momento. No hará falta leer instrucciones muy largas ni tener experiencia previa (las mecánicas serán sencillas y se podrán entender en poco tiempo). Aun así, queremos cuidar que todo sea visualmente atractivo, con un estilo claro y coherente, que dé unidad al conjunto y que moverse por la aplicación sea una experiencia fluida y agradable.

## Como jugar
!!Disclaimer¡¡: Para jugar a este juego necesitaras un Head Mounted Display.

### Minijuego 1:
Agarra la botella y agitala peleando contra la maquina, aquel que la agite de mas y le salte toda la bebida encima pierde.

### Minijeugo 2: 
Coge la espada y corta tantos chips como puedas antes de que se acabe el tiempo. ¡¡Cuidado con los disruptores que caen del cielo!!

### Minijuego 3:
Recoge el arma del taburete y dispara a todas las latas que caen del cielo antes de que se acabe el tiempo. ¡¡Apunta bien!!
